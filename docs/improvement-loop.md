# 영상 개선 실험 고리

성과 데이터로 영상을 계속 고쳐 나가는 장치다. 사람이 감으로 바꾸지 않고,
한 번에 한 가지씩 바꿔 보고 숫자로 판정한다.

## 도는 순서

1. **제작** (매일 11:00 KST): `src/experiments.py`가 오늘 날짜로 각 실험의
   팔(arm)을 정한다. 영상은 그 팔대로 만들어지고, `topic_history.json`에
   영상별 팔이 `exp`로 남는다.
2. **분석** (매일 02:17 KST, `scripts/analyze_performance.py`): 영상마다
   같은 나이에서 잰 값을 팔별로 모은다.
   - 게시 48시간 조회수 (스냅샷 사이를 직선으로 이어 읽음)
   - 첫 화면 통과율 (engagedViews ÷ views)
   - 평균 시청률 (averageViewPercentage)
3. **판정**: 팔마다 10편이 모이면 두 팔 중앙값 차이의 90% 구간을 구한다.
   - 구간이 0을 넘지 않으면: 이긴 쪽을 기본값으로 굳힌다.
   - 20편씩 모여도 갈리지 않으면: 차이 없음, 지금 쓰는 쪽 유지.
4. **다음 실험**: 끝난 실험의 칸에 대기 중인 실험을 다음 날부터 연다.

상태는 `output/experiments_state.json`에 있고, 분석 워크플로가 master에
올린다. 리포트의 `## 실험 현황`에서 진행 상황을 본다.

## 날짜로 배정하는 이유

하루 한두 편이라 영상 단위로 섞으면 같은 날 영상끼리 조건이 갈린다.
동시에 세 실험까지 돌리고 칸을 나눈다.

| 칸 | 바뀌는 주기 |
|---|---|
| 0 | 하루씩 번갈아 |
| 1 | 이틀씩 번갈아 |
| 2 | 나흘씩 번갈아 |

여드레면 세 실험의 여덟 조합이 한 번씩 나와서 서로 효과가 섞이지 않는다.

## 실험 목록 (위에서부터 차례로)

| 실험 | 비교 | 판정 지표 | 시작 |
|---|---|---|---|
| 대본 길이 | 48~55초 / 31~37초 | 48시간 조회수 | 10-02 |
| 첫 화면 숫자 카드 | 켬 / 끔 | 첫 화면 통과율 | 10-04 |
| 숫자 구간 배경 | 사진 위 카드 / 남색 정보 화면 | 평균 시청률 | 10-10 (칸 2) |
| 배경음 | 켬 / 끔 | 평균 시청률 | 대기 |
| 컷 길이 | 3초 / 2초 | 평균 시청률 | 대기 |

지정 대본(사람이 쓴 대본)은 길이 실험에서만 뺀다. 나머지 실험에는 넣는다.
자동 초안의 사실만 고친 지정 대본은 `keep_len_arm`을 켜면 길이 실험에도 들어간다
(글자 수가 그날 팔 범위일 때만).

## 실험 추가하는 법

1. `src/experiments.py`의 `REGISTRY` 끝에 항목을 넣는다(key, 팔 두 개,
   대조군, 판정 지표).
2. 제작 코드에서 `arm("key")`로 팔을 읽어 분기한다.
3. 상태 파일은 손대지 않아도 된다. 새 항목은 대기로 붙고 차례가 오면 열린다.

## 손으로 멈추거나 되돌리기

`output/experiments_state.json`에서 해당 실험의 `status`를 바꿔 master에
올린다.

- 멈춤: `"queued"` (대조군으로 돌아감)
- 판정 무르기: `"running"`으로 되돌리고 `winner`·`verdict`를 지운다.
